# UI review checklist

Used by the designer when drawing, by QA when comparing the build with the
approved mockups, and by the approver for a live walkthrough.

## How to walk it

- Use one account per user role in `CLAUDE.md`.
- Do each role in every theme the product supports (light and dark).
- Do it on a phone too, or a desktop browser narrowed to about 390px wide.
- If something looks off, take a screenshot and note the page, role, theme
  and screen size.

## On every page

1. Nothing spills sideways (no horizontal scrolling on a phone).
2. Text is readable: contrast at least 4.5:1 for body text in every theme.
3. Colour means the same thing everywhere (see the colour roles in
   `CLAUDE.md`), and colour is never the only signal.
4. Cards, buttons and inputs share the same corners, borders and spacing as
   the rest of the product.
5. The page title, short description and main action sit in the same place
   as on other pages.
6. Keyboard: every control reachable with Tab, visible focus, logical order.
7. Inputs have labels; buttons and links say what they do.
8. Touch targets are at least 44px.
9. Empty, loading and error states are present and honest — no fake data.
10. It matches the approved design version; differences are listed.
